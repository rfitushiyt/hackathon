HTML SNIPPETS

HTML 01

Basic HTML Structure

The starting structure of almost every HTML page.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">
    <title>My Website</title>
</head>
<body>

    <h1>Hello World!</h1>

</body>
</html>
HTML 02

Connect HTML with CSS

Add this inside the HTML head to connect your stylesheet.

<head>
    <link rel="stylesheet"
    href="style.css">
</head>
HTML 03

Connect HTML with JavaScript

Connect your JavaScript file before closing body.

<script src="script.js"></script>

</body>
</html>
HTML 04

Create a Navigation Link

Use anchor tags to connect different pages.

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="contact.html">Contact</a>
</nav>
HTML 05

Insert an Image

Display an image from your project folder.

<img src="images/photo.jpg"
     alt="Description of image"
     width="300">
HTML 06

Create a Form

A simple form with name, email and submit button.

<form>
    <input type="text"
    placeholder="Your name">

    <input type="email"
    placeholder="Your email">

    <button type="submit">
        Submit
    </button>
</form>

CSS SNIPPETS

CSS 07

Basic CSS Reset

Remove default spacing from HTML elements.

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
CSS 08

Connect Google Fonts

Import a Google Font into your CSS file.

@import url(
'https://fonts.googleapis.com/css2?family=Poppins&display=swap'
);

body {
    font-family: 'Poppins', sans-serif;
}
CSS 09

Center an Element

Center content horizontally and vertically.

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
CSS 10

Hover Effect

Change a button when the user moves over it.

button {
    transition: 0.3s ease;
}

button:hover {
    transform: translateY(-5px);
    opacity: 0.8;
}
CSS 11

Gradient Background

Create a colorful gradient background.

body {
    background: linear-gradient(
        135deg,
        #170A2B,
        #7200FF,
        #FF2E93
    );
}
CSS 12

Responsive Website

Adjust your design for smaller screens.

@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }

    h1 {
        font-size: 28px;
    }
}

JAVASCRIPT SNIPPETS

JAVASCRIPT 13

Display an Alert

Show a popup message in the browser.

alert("Welcome to my website!");
JAVASCRIPT 14

Get an HTML Element

Select an element using its ID.

const title =
document.getElementById("title");
JAVASCRIPT 15

Change Text with JavaScript

Change the content of an HTML element.

document.getElementById("title")
.textContent = "Hello World!";
JAVASCRIPT 16

Click Event

Run a function when a button is clicked.

const button =
document.getElementById("myButton");

button.addEventListener("click", function() {
    alert("Button clicked!");
});
JAVASCRIPT 17

Simple Function

Create a function that you can reuse.

function sayHello() {
    alert("Hello!");
}

sayHello();
JAVASCRIPT 18

Change Background Color

Change the page background using JavaScript.

document.body.style.backgroundColor
= "#7200FF";
